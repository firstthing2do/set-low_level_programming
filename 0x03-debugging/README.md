
# C - Debugging

This project focuses on debugging C programs and understanding how to test functions using main files.

## Requirements

- Allowed editors: vi, vim, emacs.
- Compiled using gcc with `-Wall -Werror -Wextra -pedantic -std=gnu89`.
- All files end with a newline.
- Betty coding style is followed.
- No global variables.
- Maximum of 5 functions per file.
- No use of the system function.

## Tasks

### 0. Positive or Negative

Create a test file named `0-main.c` that tests the `positive_or_negative()` function with an input of zero.

The function implementation is provided by the evaluator.
