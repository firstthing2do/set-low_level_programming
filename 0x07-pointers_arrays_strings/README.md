
# 0x07. C - Pointers, Arrays and Strings

This project explores pointers, arrays, memory manipulation,
and string searching in C.

## Tasks

| File | Description |
|---|---|
| 0-memset.c | Fills memory with a constant byte |
| 1-memcpy.c | Copies memory from one location to another |
| 2-strchr.c | Locates a character in a string |
| 3-strspn.c | Calculates the length of a matching prefix |
| 4-strpbrk.c | Searches for any matching character |
| 5-strstr.c | Locates a substring |
| 6-print_chessboard.c | Prints an 8x8 chessboard |
| 7-print_diagsums.c | Prints the sums of matrix diagonals |

## Compilation

Compiler: GCC

Flags:
-Wall -Werror -Wextra -pedantic -std=gnu89

## Requirements

- Ubuntu 20.04 LTS
- Betty coding style
- No global variables
- Maximum 5 functions per file
- All prototypes in main.h
- Use _putchar for output
- All files end with a newline
