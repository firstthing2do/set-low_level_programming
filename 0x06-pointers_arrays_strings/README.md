
# 0x06. C - More pointers, arrays and strings

This project covers pointers, arrays, and string manipulation in C.

## Tasks

| File | Description |
|---|---|
| 0-strcat.c | Concatenates two strings |
| 1-strncat.c | Concatenates a limited number of characters |
| 2-strncpy.c | Copies a limited number of characters |
| 3-strcmp.c | Compares two strings |
| 4-rev_array.c | Reverses an integer array |
| 5-string_toupper.c | Converts lowercase letters to uppercase |
| 6-cap_string.c | Capitalizes every word |
| 7-leet.c | Encodes a string into 1337 |

## Compilation

All files are compiled using:

gcc -Wall -Werror -Wextra -pedantic -std=gnu89

## Requirements

- Ubuntu 20.04 LTS
- Betty coding style
- No global variables
- Maximum 5 functions per file
- All prototypes in main.h
- No printf, puts, or similar output functions
- All files end with a new line
