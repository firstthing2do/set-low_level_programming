# 0x02. C - Functions, nested loops

This project introduces C functions and nested loops.

## Requirements
- Ubuntu 20.04 LTS
- GCC compiler
- Betty coding style
- Compilation with -Wall -Werror -Wextra -pedantic -std=gnu89

## Files
- main.h: Contains function prototypes.
- 0-putchar.c: Prints _putchar followed by a new line.
